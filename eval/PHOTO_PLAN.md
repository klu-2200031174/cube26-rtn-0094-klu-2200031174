# Evaluation photo set

50 held-out cases, 1 photo each, taken on 2026-09-29 with a phone under ordinary home lighting.

`eval/photo_map.csv` lists, for every case, the file, the original phone file name, the scenario it was staged for, and what is actually in the photo. `eval/eval_set.csv` gives the order each case is inspected against.

Note: no perfume bottle was available, so the "bottle + cap" item is a water bottle with a flip lid (`SKU-WATERBOTTLE-FLIP`, order ORD-HOME-91005).
